## 92. Monitor Cluster Components

모니터링 요소
- 클러스터의 노드 수, 정상 노드 수와 같은 **노드 수준 메트릭**
- CPU, 메모리, 네트워크, 디스크 사용률과 같은 **성능 메트릭**
- 파드의 수와 각 파드의 CPU 및 메모리 사용량과 같은 **파드 수준 메트릭**

<br>

모니터링 툴
- Metrics Server
    - 쿠버네티스 클러스터 당 하나의 메트릭 서버를 두고 각 쿠버네티스 노드와 파드에서 메트릭을 검색해 집계한 후 메모리에 저장함
    - 인메모리 모니터링 솔루션, 디스크에 메트릭 저장 X → 과거 데이터 알 수 X
    - kubelet에 포함된 cAdvisor(파드 성능 메트릭 검색)을 통해 Metrics Server에서 사용할 수 있도록 메트릭 노출
    - minikube에서는 `minikube addons enable metrics-server`를 통해 사용할 수 있음
    - 그 외의 환경에서는 git clone을 통해 설치 후 kubelet create -f로 구성 요소 배포 필요
    - 설치 후 `kubectl top node`와 `kubeclt top pod`로 CPU, 메모리 사용량 확인 가능
- 그 외 prometheus, elasticsearch, datadog 등이 있음

## 160. Certificates API

CA는 우리가 생성한 키와 인증서 파일 쌍임<br>
이러한 파일 쌍에 대한 액세스 권한을 얻은 사람은 누구나 Kubernetes 환경에 대한 모든 인증서에 서명할 수 있음<br>
따라서 CA는 가장 안전한 환경에서 보호하고 저장해야 하는데, 해당 서버가 CA 서버가 됨<br>
인증서 키 파일은 해당 서버에만 안전하게 저장되고, 인증서에 서명할 때마다 해당 서버에 로그인해야만 서명할 수 있음<br>
현재는 Kubernetes 마스터 노드 자체에 인증서가 배치되어 있음

인증서를 자동화된 방법으로 교체할 수 있도록 인증서 API가 있는데, 해당 API 호출을 통해 인증서 서명 요청을 Kubernetes에 직접 보낼 수 있음
1. CertificateSigningRequest API 오브젝트 생성
2. Request가 도착하면 Review 후 Approve
3. 해당 인증서를 추출하여 사용자와 공유
